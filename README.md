# Rayalaseema Mechanics Connect

R2WMS – Rayalaseema Two-Wheeler Mechanics Welfare Seva application with a clean, modern, professional UI/UX. Keep the existing PRD, features, database structure, and functionality unchanged.

Design style: Minimal, elegant, lightweight, and welcoming. Avoid heavy graphics, unnecessary animations, oversized cards, excessive gradients, and clutter. Use a professional navy blue and royal blue theme with subtle orange accents, a white background, soft shadows, and consistent spacing.

Typography: Use Inter or a similar modern font for English and a clean Telugu-supported font for Telugu content. Maintain clear heading hierarchy, readable body text, and consistent font weights.

Mobile view: Design a beautiful mobile-first experience with a clean header, association logo, notification icon, profile access, and a fixed bottom navigation bar with icons and short labels. Prioritize Home, Membership, Welfare, Notices, and Profile. Keep primary actions easy to reach with one hand.

Desktop view: Create a polished, spacious layout with a professional sidebar navigation, top header, page title, breadcrumbs where useful, dashboard summary cards, well-aligned tables, filters, and clear action buttons. Use the available screen width effectively without stretching content excessively.

UI components: Standardize buttons, input fields, dropdowns, dialogs, status badges, tables, search bars, loading states, empty states, and confirmation messages. Use consistent border radii, spacing, icon sizes, and button heights.

Interaction: Ensure smooth navigation, fast page transitions, responsive layouts, accessible forms, clear validation messages, and proper loading indicators. Avoid unnecessary animations and heavy dependencies.

Important: Preserve all existing features, routes, authentication, Supabase integration, database schema, and security policies. Do not replace working functionality with mock data. Reuse existing components where possible and make changes incrementally.

Goal: Deliver a premium-looking, easy-to-use association application that feels welcoming to mechanics of all ages, works beautifully on mobile phones, and looks professional on desktop computers. Demo login Admin and user can create own account use local storage
